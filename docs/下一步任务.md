# 下一步任务

骨架已经跑通了。下面是按顺序要补的功能，每完成一项就打勾，并 `git commit` 一次。

原则：**一次只做一件事，做完必须能跑起来再往下走。**

---

## 第 1 步：新增错题（对应 D8）

- [ ] 在 `routes/records.py` 里把 `new_record` 改成 `methods=["GET", "POST"]`
- [ ] 新建 `templates/record_form.html`，新增和编辑共用
- [ ] GET 时渲染空表单
- [ ] POST 时用 `request.form.get("title")` 取字段
- [ ] 校验：`title` 不能为空；`difficulty` 必须在 1~5 之间
- [ ] `INSERT INTO records ...`，用 `cursor.lastrowid` 拿到新 id
- [ ] 标签：按名字查 `tags`，没有就插入；然后写 `record_tags`
- [ ] 用 `flash("保存成功")` + `redirect(url_for("records.list_records"))`

**验收**：表单提交后回列表页，新记录在最上面；故意留空标题会被拦下。

---

## 第 2 步：编辑与删除（对应 D9）

- [ ] 编辑：GET 时把原值填进表单；POST 时 `UPDATE ... WHERE id=? AND user_id=?`
- [ ] 删除：`<form method="post">` + 一个提交按钮（不要用 `<a>` 链接删）
- [ ] 删除后 `flash` 提示并跳回列表

**验收**：改完刷新还是新值；删掉后列表里没了。

## 第 3 步：注册 / 登录（对应 D10）

- [ ] `routes/auth.py` 里实现 `register`：`generate_password_hash(password)`
- [ ] 实现 `login`：按用户名查人 + `check_password_hash` + `session["user_id"] = id`
- [ ] 实现 `logout`：`session.clear()`
- [ ] `app.py` 里把导航栏的「登录」换成「登录 / 退出」，登录后显示用户名

**验收**：注册能登进去；密码错会提示"用户名或密码错误"；关掉浏览器重开还是登录状态（session 生效）。

## 第 4 步：权限隔离（对应 D11，最重要的一步）

- [ ] 把 `routes/records.py` 顶部的 `DEMO_USER_ID = 1` 删掉
- [ ] 改成每次从 `session.get("user_id")` 取
- [ ] 加一个 `@bp.before_request`：没登录就 `redirect(url_for("auth.login"))`
- [ ] 检查所有 SQL 的 `WHERE` 都带 `user_id = ?`

**验收**：用两个账号各建一条记录，互相看不到；手动改 URL 里的 id 会 404。
**这一步做对了，"越权访问"就是简历上能讲的真实经历。**
